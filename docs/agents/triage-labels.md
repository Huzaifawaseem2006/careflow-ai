# Triage labels

The tracker uses these canonical status strings:
`needs-triage`, `needs-info`, `ready-for-agent`,
`ready-for-human`, and `wontfix`.
Use the matching string in each issue's `Status:` line during triage.
After acceptance criteria are verified, use `resolved` as the completion state
per [the tracker workflow](issue-tracker.md); it is not a sixth triage label.
