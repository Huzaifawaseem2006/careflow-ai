# Issue tracker: Local Markdown

Issues and specs live under `.scratch/<feature-slug>/`.
The spec is `spec.md`; implementation tickets are separate
`issues/<NN>-<slug>.md` files, numbered from `01`.
Record triage as a `Status:` line near the top of each ticket.
Append discussion under `## Comments`.
When a skill says to publish an issue, create the appropriate file;
when it says to fetch one, read the referenced path.
